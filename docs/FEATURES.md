## このアプリだけの機能

- 起動時に前回の内容を即座に表示 (その後サーバーの最新に置き換え)
- 背面から戻ったときに自動で再接続し、取りこぼしを取り直す
- 画像が読み込めなかったら枠の中に「読み込めませんでした・押して再読み込み」を出し、押す・リアルタイム接続がつながり直すと出し直す。サーバーから消された画像 (404) は「ファイルがサーバーにありません」(D-076)。単体テストと S (全画面表示の 404)
- 使っている途中で接続が切れたら、3 秒続いたところでチャンネルの題名の下 (ホームは上の行) に知らせ、つながったら「つながりました」を出して消す (D-073)
- アプリを閉じていても通知 (プッシュ通知。配信アプリ不要) / 常時接続モード
- チャンネルごとの下書き保持 (アプリを閉じても残る)、送信失敗時の入力内容の復元
- 電波が無いときに送ったメッセージを「送信待ち」にして、つながったら送る (アプリを閉じても残る)。E で機内モードにして確認
- LAN 内のサーバーに Android 17 でも接続できる (必要なときだけ「付近のデバイス」の権限を求める)。E (API 37)
- 通知から直接「返信」「既読にする」。別の端末で既読にした通知は消える。通知は送信者のアイコン付きの「会話」の形でチャンネルごとにまとめる
- 管理者によるパスワードのリセット・ユーザーの削除 (サーバーの API はあるが Web 版には無い)
- 他のアプリの「共有」から画像・ファイル・文章を送る。添付を他のアプリへ共有する
- 端末のフォントで描けない絵文字の除外
- 外付けキーボードで Enter 送信 (Shift+Enter で改行)
